# Components Directory

This directory will contain React components organized by domain:

- `layout/` — App shell, page containers
- `navigation/` — Desktop and mobile navigation
- `common/` — Shared UI primitives (buttons, cards, badges, inputs)
- `dashboard/` — Dashboard-specific components
- `market/` — Market intelligence components
- `forecast/` — AI forecast components
- `resources/` — Resource catalogue and detail components
- `bookings/` — Booking flow components

Components will be created during Stitch-gated implementation phases.
